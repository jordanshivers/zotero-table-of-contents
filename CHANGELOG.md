# Changelog

## 1.1.1

- Keep highlights on the right entries when the list is expanded, collapsed,
  or filtered.

## 1.1.0

- Select several entries with Cmd/Ctrl-click or Shift-click, then right-click
  to move, nest, or delete them together.

## 1.0.1

- Fix a "can't access dead object" error when switching between PDFs.

## 1.0.0

- Add entries for the current page from a button in the contents sidebar.
- Right-click an entry to rename it, point it to the current page, add an
  entry below or inside it, move it up or down, nest it, move it out a level,
  or delete it with its sub-entries.
- Edit bookmarks that were already in the PDF in the same way.
- Save an original and a previous copy of the PDF before each edit, and check
  the new file before replacing the old one.
